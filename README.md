# iFCM — Город заботы

Сайт-концепт для iFCM GROUP. Публикуется через GitHub Pages.

- `index.html` — сама страница (3D-город, конструктор сервиса, новости).
- `content.json` — все тексты, услуги, блоки и новости. Его меняет админка, руками трогать не нужно.
- `img/` — фото из шаблона презентаций iFCM.
- `uploads/` — фото, загруженные через админку (папка появится сама).

Адрес бэкенда указан в начале скрипта в `index.html`, строка `const BACKEND_URL = ...`.
