# iFCM — Город заботы

Сайт-концепт для iFCM GROUP. Публикуется через GitHub Pages.

## Страницы
- `index.html` — главная: 3D-город, конструктор сервиса, плитки услуг, блоки, новости, форма.
- `about.html` — О нас: кто мы, миссия, цель, ценности, безопасность, документы.
- `services.html` — Услуги: 4 направления с полными списками услуг.
- `suppliers.html` — Поставщикам: положение для поставщиков и все документы.
- `career.html` — Карьера: преимущества, отзывы сотрудников, отклик.
- `contacts.html` — Контакты: офис, телефон, почта, форма обращения.

## Файлы
- `content.json` — тексты главной, услуги конструктора, блоки, новости, контакты. Меняется через админку.
- `assets/config.js` — **адрес бэкенда на Render** (одна строка, для всех страниц).
- `assets/site.css`, `assets/nav.css`, `assets/site.js` — общие стили, шапка с меню, подвал, формы.
- `img/` — фото из шаблона презентаций iFCM; `uploads/` — фото из админки (появится сама).
